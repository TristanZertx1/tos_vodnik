Проект ТОС «Водники»

Windows: запустите start-site.cmd. Окно PowerShell останется открытым; для остановки нажмите Ctrl+C.
Нужен Node.js 22.13 или новее. Скрипт установит зависимости из package-lock.json и откроет сайт на http://localhost:5173.

При первом запуске проект автоматически подготовит локальную базу D1, применит миграции и создаст аккаунт администратора. Логин: admin. Одноразовый случайный пароль будет показан в терминале — сохраните его. Повторные запуски сохраняют базу и пароль. Секреты в архив не входят; локальный хеш сохраняется только в .dev.vars.

Если забыли пароль, остановите сайт, удалите строку CMS_ADMIN_HASH из .dev.vars и запустите проект снова.
