# Установка сайта «Водники» на хостинг reg.ru

Сайт работает на обычном хостинге reg.ru: статические страницы, PHP-API и база MySQL — всё на российских серверах.

## 1. Подготовка в панели reg.ru

1. Выберите PHP 8.1 или новее для домена `tos-vodniki.ru` (раздел PHP-настроек).
2. Создайте базу MySQL: имя базы, пользователь и пароль. Запишите их, адрес сервера обычно `localhost`.
3. Убедитесь, что SSL-сертификат для домена включён (адрес открывается по `https://`).

## 2. Загрузка файлов

Загрузите содержимое папки после сборки (через FTP-деплой из GitHub или файловый менеджер) в корень домена. В корне должны оказаться `index.html`, `.htaccess`, папки `api/`, `fonts/` и остальные файлы.

## 3. Настройка API

1. В папке `api/` создайте файл `config.php` на основе `config.example.php`.
2. Заполните блок `db`: `host`, `name`, `user`, `pass` из шага 1.
3. Задайте `setup_token` — длинную случайную строку, например 40 символов.
4. Для уведомлений о записях укажите `notify_email` (необязательно).

Файл `config.php` не попадает в репозиторий и не перезаписывается при деплое.

## 4. Первая установка

1. Откройте `https://tos-vodniki.ru/api/setup.php`.
2. Введите установочный код из `config.php` и пароль администратора (не короче 10 символов).
3. Установщик создаст таблицы, учётную запись `admin` и загрузит начальные материалы.
4. **Сразу удалите файл `api/setup.php`** через файловый менеджер или FTP. Пока он на месте, установщик доступен по адресу.

## 5. Проверка

- `https://tos-vodniki.ru/api/public/content` возвращает JSON с разделами сайта.
- `https://tos-vodniki.ru/admin/` открывает вход в панель; после входа видны материалы, регистрации и статистика.
- `https://tos-vodniki.ru/politika` открывает политику обработки персональных данных.
- Запись на мероприятие с отметкой согласия сохраняется, а число свободных мест меняется.

## Обслуживание

- Резервные копии: раз в неделю экспортируйте базу MySQL в панели reg.ru.
- Заявки на мероприятия удаляйте по окончании мероприятия или по требованию участника (кнопка «Отменить» в панели отменяет заявку; полное удаление делается через phpMyAdmin).
- Пароли: меняйте пароль администратора раз в полгода и при смене состава редакторов.
