# Индивидуальный дизайн ТОС «Водники»

Источник настроения: https://садвлукино.рф/ — округлые формы, зелёные и оранжевые акценты. Оригинальные шрифты образца: Nauryz и Kabel. Используемые шрифты: Comfortaa и Nunito (SIL Open Font License), локальные файлы и лицензии находятся в public/fonts.

Новый дизайн: тёплый кремовый фон, глубокий зелёный для текста и навигации, мягкий оранжевый для основных действий, авторская векторная иллюстрация микрорайона у реки. Исходный логотип сохранён.

Figma: https://www.figma.com/design/OkLJKppvqgESdG9CeZGJzC
Файл создан, но создание макетов остановлено лимитом MCP на тарифе Starter. Завершённого макета в файле нет. Сценарий восстановления макетов: figma-layout.js. Не считать сценарий визуально проверенным.

Реализация: public/design.css, public/neighborhood.svg. Публичная ссылка на /admin/ удалена; прямой URL и CMS продолжают работать.
