# Панель управления

Адрес: `/admin/`. Первоначальный пароль администратора задан заказчиком и настроен как серверный хеш в секретной переменной CMS_ADMIN_HASH. Его нет в исходниках и браузерном коде.

## Локальный запуск

В локальной сборке база D1 подготавливается автоматически при `npm run dev` или `npm run start`: запускаются все миграции из `drizzle/`, в том числе для ранее созданной базы. Материалы при повторной подготовке не удаляются. При первом запуске создаётся локальный аккаунт `admin` со случайным паролем. Сохраните пароль из терминала: он больше не показывается. В корне проекта хранится только PBKDF2-хеш в `.dev.vars`; этот файл исключён из Git и архива.

Локальная учётная запись отдельна от production. Для сброса локального пароля остановите сервер, удалите строку `CMS_ADMIN_HASH` из `.dev.vars` и снова запустите сайт. Скрипт создаст новый пароль и выведет его в терминал.

Панель использует серверную базу D1. Новости, мероприятия, проекты и документы можно создавать, редактировать, удалять и сохранять как черновики. Публикация отображается на сайте сразу при следующей загрузке страницы. Фотографии и документы добавляются ссылками на реальные файлы; фото требуют подтверждения права на размещение и описания.

Администратор создаёт модераторов, отключает и включает их доступ, сбрасывает пароли и удаляет аккаунты. Модератор управляет материалами и своим паролем, но не пользователями и контактами. Отключение доступа или сброс пароля отзывает активные сессии.

Вход в панель защищён отдельным логином и паролем; подтверждение посетителя через ChatGPT не требуется. Доступность самого сайта регулируется настройками среды, в которой он размещён. Пароли и права редакторов проверяются сервером.

Сессии действуют 8 часов и хранятся в HttpOnly Secure SameSite cookie. Все изменяющие запросы проверяют Origin и токен CSRF. Пароли хешируются PBKDF2-SHA256. Есть ограничение попыток входа и проверка конфликта версий материалов.

Общие тексты, наименование, адрес и реквизиты продолжают храниться в site-source/app.js. Проверочный список BEFORE-PUBLICATION.md сохраняет силу. Данные пользователей и опубликованных материалов находятся в D1; исходный архив сайта не содержит резервную копию базы.
