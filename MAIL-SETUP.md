# Уведомления о записи на мероприятия

После публикации кода задайте в Cloudflare Worker `tos-vodniki-admin-api` следующие переменные окружения:

- `RESEND_API_KEY` — API-ключ Resend.
- `NOTIFY_EMAIL` — адрес, на который присылать заявки, например `vshivkova.anna@bk.ru`.
- `MAIL_FROM` — подтверждённый адрес отправителя в Resend. Для теста можно оставить значение по умолчанию `ТОС «Водники» <onboarding@resend.dev>`.

В Resend нужно подтвердить домен отправителя или использовать тестовый адрес. Ключ хранится только в настройках Worker и не попадает в браузер или репозиторий.

Письмо отправляется после успешного сохранения заявки в D1. Если почтовый сервис временно недоступен, сама запись не теряется: администратор увидит её в панели управления.
